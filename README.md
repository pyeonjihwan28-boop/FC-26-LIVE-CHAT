# FC 26 해설 → AI 가상 라이브 채팅

EA SPORTS FC 26의 한국어 중계 해설을 실시간으로 알아듣고, Claude Haiku가 유튜브 라이브 채팅처럼 시청자 반응을 만들어 OBS 오버레이에 띄웁니다. 골이 들어가면 채팅이 폭주하고, 빌드업 중엔 잔잔하고, 해설이 없으면 잡담이 오갑니다.

```
게임 소리 ─▶ 해설 구간 잘라내기 ─▶ 한국어 음성 인식 ─▶ Claude Haiku ─▶ 채팅 오버레이
(WASAPI 루프백)  (Silero VAD)          (faster-whisper, 로컬)   (스트리밍)     (OBS 브라우저 소스)
```

LLM은 Claude Haiku 4.5 (API)만 쓰고, 음성 인식은 내 PC에서 돌아가서 추가 요금이 없습니다.

## 준비물

- Windows 10/11, **Python 3.12** (3.11도 가능)
- Anthropic API 키 (https://platform.claude.com)
- NVIDIA 그래픽카드 권장. 없어도 CPU로 돌아가지만 인식이 느리고 덜 정확합니다.

## 설치

```bat
cd fc26_live_chat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-gpu.txt      :: NVIDIA GPU가 있을 때만 (약 1GB)
copy .env.example .env                   :: 메모장으로 열어서 API 키 입력
```

## 실행

**`실행.bat` 더블클릭**이면 끝입니다. 처음 실행 때는 가상환경 만들기·패키지 설치(NVIDIA GPU가 있으면 GPU 패키지까지)를 자동으로 하고, `.env`가 없으면 메모장을 열어 API 키를 넣게 합니다. 옵션도 그대로 넘길 수 있습니다 (`실행.bat --text`).

직접 실행하려면:

```bat
python main.py
```

첫 실행 때 음성 인식 모델을 내려받습니다 (GPU: large-v3-turbo 약 1.6GB, CPU: small 약 0.5GB). 콘솔에는 `🎙 인식된 해설`, `💬 생성된 채팅`, 호출마다 누적 비용이 찍힙니다.

### 채팅·라인업 창

실행하면 **채팅 창**(오른쪽 위)과 **라인업 창**(왼쪽 위)이 자동으로 뜹니다. 채팅 창은 가장자리를 끌어서 크기를 바꿀 수 있고, 라인업 창은 `lineup.json`이 바뀌면 1초 안에 다시 그려집니다. 창 하나를 닫으면 프로그램이 종료됩니다.

- OBS: 소스 추가 → **윈도우 캡처** → `[python.exe]: 실시간 채팅` / `[python.exe]: 라인업`
- 설정은 `config.py`의 `WINDOW_...` (글자 크기, 항상 위, 해설 자막 표시, 한 팀만 등)
- 창 없이 브라우저 오버레이만 쓰려면 `python main.py --no-window`
- `python overlay_app.py`: 서버 없이 가짜 채팅으로 창 모양 미리보기

### OBS에 올리기 (브라우저 소스)

창 대신 투명 배경 오버레이를 쓰고 싶을 때: 소스 추가 → **브라우저** → URL에 `http://127.0.0.1:8765/?transparent=1`, 너비 400 · 높이 700 정도.

주소 뒤에 옵션을 붙일 수 있습니다 (`&`로 연결): `size=16` 글자 크기, `bg=0.4` 반투명 배경, `max=40` 최대 줄 수, `header=0` 헤더 숨김, `debug=1` 인식된 해설을 위에 표시.

### 라인업 오버레이 (라리가 스타일)

소스 추가 → **브라우저** → `http://127.0.0.1:8765/lineup?transparent=1`, 너비 660 · 높이 520 정도.

`lineup.json`에 팀 이름·약칭·포메이션·유니폼 색·선수(등번호, 이름)를 적고 저장하면 3초 안에 화면이 바뀝니다. 선수는 **골키퍼 → 수비 → … → 공격** 순서, 같은 줄에선 **왼쪽부터** 적으세요. 인원이 포메이션과 안 맞으면 카드 아래에 경고가 뜹니다. 줄무늬 유니폼은 `kit`에 `"stripe"` 색을 넣으면 됩니다.

**게임 화면에서 자동으로 읽기** — `실행.bat`을 켜 두고 감독 커리어 모드에서 아래 화면을 차례로 잠깐씩 띄우면 됩니다. 화면 판별은 Windows 내장 OCR(무료), 읽기는 Claude Haiku(화면당 약 0.4~0.7센트, 같은 화면이면 다시 안 읽음).

| 순서 | 게임 화면 | 알아내는 것 |
|---|---|---|
| 1 | 커리어 홈(센트럴) | 다음 경기 두 팀·대회·날짜, 오른쪽 위 내 팀 → 홈/원정 자동 설정 |
| 2 | 팀 관리 → 스쿼드 | 우리 선발 11명·포메이션 |
| 3 | 상대 분석 → 예상 라인업 | 상대 선발 11명·포메이션 (매치데이엔 센트럴에 '상대 분석' 버튼 → 채팅 창에 눌러 달라고 표시) |
| 4 | 경기 화면 | 왼쪽 위 스코어보드 시계가 보이면 **경기 중 → 채팅 송출** |
| (필요할 때) | 경기 중 일시정지(선발 라인업·벤치) | 한 팀이라도 포메이션을 못 읽었으면 이 화면으로 다시 읽음 + 실제 등번호로 맞춤 |

**채팅은 1~3을 다 읽고 경기가 진행 중일 때만 송출됩니다** (채팅 창에 남은 것이 ○/● 로 표시). 일시정지·리플레이·하프타임(스코어보드가 90초 안 보여도)은 경기 중으로 보고, 커리어 메뉴가 보이면 바로 멈춥니다. 다음 경기로 넘어가 센트럴에 새 경기가 뜨면 새 선발을 읽을 때까지 다시 대기. 채팅 창 **우클릭**: 채팅 바로 시작(대기 건너뛰기) / 설정(내 팀 직접 입력).

- **FC 26이 화면에 없으면**(최소화·꺼짐·다른 프로그램에 가려짐) 캡처하지 않고 채팅 창에 게임을 띄워 달라고 표시합니다. 채팅·라인업 창이 게임 위에 있는 건 괜찮습니다 — **캡처하는 순간에만 두 창을 캡처에서 빼서**(화면에는 그대로 보임, 깜빡임 없음) 게임 화면만 읽습니다.
- 포메이션은 선수 이름표 높이로 줄을 나눠서 계산하고(FC 26에 있는 포메이션이 되도록 검사), 스쿼드 화면의 큰 숫자는 능력치라서 등번호로 쓰지 않습니다(등번호는 실제 소속 클럽 번호, 한 번 정해지면 유지).
- 잘린 이름("Lamine Yam", "ee Seung Wc")은 포지션·동료·축구 지식으로 맞추고, 추측한 선수는 콘솔에 표시됩니다. 얼굴로 선수를 판별하지는 않습니다.
- 게임이 **전체 화면(독점)**이면 캡처가 검게 나오고 창도 가려지니 **테두리 없는 창** 모드를 쓰세요.
- 직접 실행: `python lineup_scan.py me|opp` (5초 안에 게임 화면으로 전환, `--image 스샷.png`도 가능), 화면 판별 테스트: `python screen_watch.py --image 스샷.png`

옵션: `side=home` 한 팀만, `dir=column` 위아래 배치, `scale=1.2` 크기. `lineup.html`을 더블클릭하면 서버 없이 예시로 미리보기.

## 게임 소리 입력

기본값은 **기본 스피커로 나가는 소리 전체**입니다. 디스코드나 음악도 같이 들어가니 방송 중엔 게임 소리만 나오게 하는 게 좋습니다.

- **콘솔 + 캡처보드**: `python main.py --list-devices`로 캡처보드 오디오 번호를 찾고 `python main.py --device 번호`
- **게임 소리만 따로 받기**: Windows 설정 → 시스템 → 소리 → 볼륨 믹서(Windows 10은 '앱 볼륨 및 장치 기본 설정')에서 FC 26의 출력 장치를 가상 오디오 케이블 같은 별도 장치로 지정하고, 그 장치를 `--device`로 선택. 이때 내 귀에도 들리게 하려면 해당 녹음 장치 속성에서 '이 장치로 듣기'를 켜면 됩니다.

게임 오디오 설정에서 **해설 볼륨을 올리고 관중·음악 볼륨을 조금 낮추면** 인식률이 눈에 띄게 좋아집니다.

## 튜닝 (config.py)

- **방송 배경·시청자**: `CHANNEL_NAME`(유튜브 채널 이름), `EXTRA_CONTEXT`(경기 배경), `FANS`(팬 구성·시청자 수), `VIEWERS`(자주 오는 시청자 성격) / 더 깊게는 `chat_brain.py`의 `SYSTEM_PROMPT`
- **선수 이름이 이상하게 나올 때**: `PLAYER_NAMES`에 내 스쿼드 선수 이름
- **반응이 늦을 때**: `VAD_MIN_SILENCE_MS`↓, `VAD_MAX_SEGMENT_SEC`↓, `STT_BEAM_SIZE = 1`
- **관중 소리에 헛인식할 때**: `VAD_THRESHOLD`↑ (0.6~0.7)
- **채팅 속도감**: `MSG_GAP_SEC`
- **비용 줄이기**: `MIN_CALL_GAP_SEC`↑ (3~5초로 하면 여러 해설을 묶어서 한 번에 호출)

## 문제 해결

- **"12초째 소리가 안 들어옵니다"**: 게임 소리가 다른 장치로 나가고 있습니다. `--list-devices`로 확인 후 `--device`.
- **GPU 오류 (`cublas64_12.dll`, `cudnn_ops64_9.dll` 등)**: `pip install -r requirements-gpu.txt`를 했는지 확인. 실패하면 자동으로 CPU로 전환됩니다. 프로그램이 메시지 없이 꺼지면 `STT_DEVICE = "cpu"`로 두고 쓰세요.
- **게임 프레임이 떨어짐**: `STT_COMPUTE_TYPE = "int8_float16"` 또는 `STT_MODEL = "small"`
- **"시청해주셔서 감사합니다" 같은 엉뚱한 문장**: Whisper가 소음에서 지어내는 문장이라 자동으로 걸러집니다. 다른 패턴이 계속 보이면 `stt.py`의 `HALLUCINATIONS`에 추가.

## 유튜브 라이브 느낌

- 배경은 스포츠 채널(`CHANNEL_NAME`)의 **유튜브 축구 생중계 라이브**입니다. 게임·스트리머(방장) 얘기는 채팅에 안 나옵니다.
- **시청자 수** (채팅 창 위 `○○명 시청 중`): 경기가 바뀌면 Haiku에게 두 팀의 전 세계 팬 수를 물어서(경기당 1회 약 0.1센트, `audience.json`에 저장해 재사용) **(두 팀 팬 합) × 1.5 ÷ 10,000**이 평균 시청자입니다.
  - 중계 멘트에 따라 변합니다: 경기 전 70% → 킥오프 100%, 골 +10~15%(몇 분에 걸쳐 빠짐), 결정적 장면·한국 선수 장면 +2~4%, 하프타임 85%, 멘트 없이 1분 넘으면 조금씩 감소, 경기 종료 후 55%.
- **팬 구성**: 홈 팬 : 원정 팬 = 팬 수 비율, 거기에 중립 축구팬 33%. 선발에 **한국 선수가 있으면 중립 팬은 전부 그 팀 응원**(양 팀 다 있으면 반반). 채팅 AI가 이 비율대로 채팅을 칩니다.
- 유튜브에 없는 '단골' 표시는 없습니다. 자주 오는 시청자는 내부 기록(`viewers.json`)으로만 남고, 채팅창엔 유튜브처럼 **멤버십(초록)·매니저(파란)** 색과 **슈퍼챗**, **새 멤버** 환영 카드만 보입니다.
- 끄려면 `config.py`의 `FANS = "mixed"` 또는 `"neutral"` (시청자 수 표시 없음).

## 경기 중 자동으로 하는 것

- **스코어·득점자**: 화면 아래 '공 가진 선수'(예: `15 RODRI`)를 계속 기록하고, 골 멘트가 나오면 왼쪽 위 스코어보드를 Haiku로 읽어서(1회 약 0.1센트) 점수가 오른 팀의 직전 공 가진 선수를 득점자로 기록 → 채팅이 득점자를 연호. 멘트를 놓친 골도 90초마다 스코어보드 확인. 공 가진 선수 표시의 등번호로 lineup.json 등번호도 자동 수정.
- **누적 득점 기록**: 경기가 끝나면(경기 종료 멘트 또는 85분 이후) 득점자를 `career_stats.json`에 쌓음 → 다음 경기부터 채팅에 "누적 N호골" 반영. 지우면 처음부터.
- **일시정지**: 일시정지 메뉴(경기 재개)·경기 중 팀 관리 화면이 보이면 채팅을 가리고 '경기 재개'를 눌러 달라고 표시.
- **다시 켰을 때**: 이미 라인업이 매핑돼 있으면 경기 화면(킥오프)이 보이는 순간 바로 채팅 시작.

## 채팅 AI 프롬프트와 자가 개선

- 채팅 AI에게 보내는 글은 전부 **`prompt_template.md`** 에 있습니다 (시스템 프롬프트, 매번 붙는 경기 정보·스코어·누적 득점 양식 등). 고치고 저장하면 다음 호출부터 반영.
- **자가 개선** (`prompt_coach.py`): 경기 중 4분마다 Haiku가 최근 중계 멘트와 채팅을 보고 어색한 말투·상황과 안 맞는 채팅을 찾아 `[LEARNED]` 규칙을 추가·삭제합니다 (1회 약 0.5센트). 기본 규칙·출력 형식은 안 건드리고, 고치기 전 파일은 `prompts_history/`, 평가 내용은 `prompt_review_log.jsonl`. 끄려면 `config.py`의 `PROMPT_COACH = False`.

## 비용

Haiku 4.5는 100만 토큰당 입력 $1 / 출력 $5입니다. 호출 한 번이 입력 약 1.5~2천 토큰 + 출력 100~400 토큰 정도라 **호출당 약 0.2~0.4센트**입니다. 해설이 쉴 새 없이 나오면 시간당 호출이 수백 번이 될 수 있으니, 콘솔의 누적 비용을 보면서 `MIN_CALL_GAP_SEC`로 조절하세요. 해설이 5분 넘게 없으면 잡담 호출도 멈춥니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `main.py` | 실행, 오버레이 서버(WebSocket), 음성 처리 스레드 연결 |
| `audio_input.py` | 게임 소리 캡처(WASAPI 루프백/입력 장치), 파일 재생, 16kHz 변환 |

| `chat_brain.py` | Haiku 프롬프트, 스트리밍 응답을 한 줄씩 바로 채팅으로, 사람 같은 시간차 |
